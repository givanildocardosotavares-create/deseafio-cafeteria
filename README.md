# Café Aroma

Página web de uma cafeteria, feita em HTML e CSS para o Desafio Prático de Coding (Uninassau).

## Conteúdo
- Cabeçalho e menu de navegação
- Seção principal
- Produtos, depoimentos e sobre
- Rodapé

## Versionamento
Projeto versionado com Git e GitHub, com branch paralela (`melhoria-cards`), revert de erro proposital e merge.
